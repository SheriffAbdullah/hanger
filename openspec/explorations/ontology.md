# Ontology — THE MAP (tree / decision-graph)

Level 0 = universal INFERENCES. Under each: OS-specific COLLECTORS. Weight: **light** ≤300ms · **heavy** >1s/compile/service. Policy: `run-always | run-when-calm-only | defer-to-post-trace | skip-with-reason`. Per inference: direct? + rules + TBD.

## Inferences → collectors
1. `power.on_wall_power` — Win: `PowerStatus.PowerLineStatus` (user, light, run-always). Mac: `pmset -g batt`. Direct yes. Rules: none.
2. `power.battery_pct` — Win: `BatteryLifePercent` + `Win32_Battery` (user, light, run-always). Mac: `ioreg AppleSmartBattery`. Direct yes. Rules: AC-vs-BAT.
3. `power.throttled` — Win: `% of Maximum Frequency` + `powercfg /GETACTIVESCHEME` + `Get-PnpDevice *DTT*` (user, light, run-always); EcoQoS P/Invoke top-8 (user, heavy ~2s compile, defer-to-post-trace; melting → `{deferred}`); ThermalZone temp (admin, light, skip-with-reason → maxFreq proxy). Mac: `powermetrics -s cpu_power`. Direct no (maxFreq<60% on AC OR eco=1 at hang). Rules: throttle alibi. TBD: AC/DC baselines; HP-Optimized cap point.
4. `mem.committed_pct` — Win: `Memory\% Committed Bytes` in probeBundle Get-Counter (user, light, run-always). Mac: `vm_stat`/`hw.memsize`. Direct yes. Rules: PRESSURE_COMMIT (85, severe 90). TBD: scale by RAM.
5. `mem.pressure` — Win: committed + Available MBytes + Standby Normal/Reserve + Modified + Lifetime, same bundle (user, light, run-always); Pool Nonpaged 15s/on-HANG; Pagefile% bundled. Mac: `memory_pressure` (±1 of Activity color). Direct no (commit≥85 OR free<2GB→severe). Rules: PRESSURE_COMMIT/SUSTAINED (over85 ≥ DUR×0.3), LOW_FREE (2.0/1.5GB), VERDICT BOUND/PRESSURED/OK. TBD: minFree by RAM; sustained window.
6. `mem.thrashing` — Win: `Pages/sec + Page Reads/sec + Pages Input/sec` bundled (user, light, run-always). Mac: `vm_stat pageouts` Δ. Direct no (>500 sustained 5s avg; spike≠proof). Rules: THRASH_PAGES. TBD: avg window.
7. `cpu.saturated` — Win: Queue Length + %ProcessorTime + DPC%/Interrupt% bundled (user, light, run-always); per-proc User+Priv top-8 (light, defer-to-post-trace). Mac: `top -l1` loadavg / powermetrics. Direct no (queue>4; spin cpu~100 vs I/O-wait cpu-low+hang). Rules: CPU_SAT. TBD: per-core normalization.
8. `disk.stalled` — Win: per-vol queue + sec/Transfer + Bytes R/W PDH (user, light, run-always); pagefile-vs-app volume map CIM once (light, run-always); SMART `Get-PhysicalDisk | Get-StorageReliabilityCounter` (admin, skip-with-reason → counters-only). Mac: `iostat -d` / `fs_usage`. Direct no (sec>0.025 AND queue≥1; queue=0→false). Rules: DISK_STALL. TBD: SSD vs HDD sec.
9. `proc.top_hoarders[]` — Win: `tasklist CSV` rollup (user, light, run-always; melting → defer re-snapshot while lastSnapMs>2000); `Get-Process` WS/Private top-5 + on-HANG (defer-to-post-trace); dwm/warp MB on-HANG; per-engine GPU `(*)` (heavy, run-when-calm-only); SeDebug (admin, skip-with-reason). Mac: `ps -axm` + `footprint` (Σ≈used ±10%). Direct yes for rank (Private ΔMB; shareable≈WS−PM kills mirages). Rules: culprit confidence (0.4·share+0.3·co-occur+0.2·paging+0.1·event, cap 0.95) [NOT IMPLEMENTED; see DEF-2 in openspec/IMPLEMENTATION-PLAN.md §6.5] [SUPERSEDED: confidence is now derived from recorded evidence components by the diagnosis engine (openspec/changes/diagnosis-engine-rebuild); correlation deferred, DEF-2]. TBD: top-N 5 vs 8.
10. `proc.identity_unresolved` — Win: Responding+Path + FileDescription top-8 + `svchost -s` (user, light, defer-to-post-trace); CommandLine depth≤3 (run-when-calm-only, redaction burden); Sysmon ID1/5 (admin-read, skip-with-reason). Mac: bundle-id lookup. Direct yes (0-or-flagged). Rules: data-quality gate.
11. `hang.events[]` — Win: `node -e ""` spawn 30–80ms (user, light, run-always — IS the hang) + timer-slack + echo/file-read baselines (run-always) + user marks (free). Mac: same spawn + `spindump`; ctx ±10s non-null. Direct yes (ms≥HANG_MS). Rules: STALL (--hang 800), RECOVERY_OK (400), CONTEXT_WINDOW (±10s); LOOP_CONF excluded. TBD: calibrate vs user-marks precision/recall.
12. `hang.os_confirmed` — Win: `Responding=false` + App 1002 rows (user, light, defer-to-post-trace); DebugDiag dump (admin+install, skip-with-reason). Mac: `log show` hang predicate. Direct yes. Rules: OS_HANG (count>0).
13. `sys.os_events` — Win: App 1000/1001 + Sys 2004/41 batch (user, light, defer-to-post-trace); WER counts (user-own / admin-full, skip-with-reason partial); MemDiag read (admin, never trigger); sleep-study/battery-report (admin one-shots, run-when-calm-only). Mac: `log show` crash/hang. Direct yes. Rules: crash-vs-hang / exhaustion-vs-reboot splits.
14. `container.state` — Win: `docker ps` + vmmem WS + `wsl -l -v` + pg_settings/Redis INFO (user, light, run-always — survives freeze); `docker stats` (heavy, blocks when frozen → run-when-calm-only); full inspect/keyspace (run-when-calm-only or on-HANG with timeout). Mac: `docker ps`; colima/lima. Direct yes. Rules: none (never gates verdict).

## Decision procedure (given a HANG, top-down)
1. Cheapest sufficient first: `hang.events` → `mem.pressure/committed/thrashing` (same PDH bundle, zero extra calls) → `cpu.saturated/disk.stalled` (same bundle) → `power.throttled` (cached plug/scheme + bundled maxFreq).
2. If an inference decides (commit 97% + pages>500 → RAM-BOUND), stop; never escalate to heavy.
3. Else degrade: defer-to-post-trace → run-when-calm-only → skip-with-reason (WPR if disk<2GB, admin if tier=user, missing counters→`unknown` never 0).
4. Slip budget governs: `slipS/bundleMs/snapMs/ecoMs` first-class; slipS>2 → keep row, widen W, never interpolate. All-green + load = calm proof; all-green + no load = `insufficient-load — rerun under real workload`.
5. Terminal: **cannot observe at all is evidence** — record attempt + failure mode (`skipped-overload`, `tier=user`, `wprEtl=null`).
