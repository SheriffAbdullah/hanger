# Deep Thermal + Throttle Truth (Windows laptop, no admin; HP ProBook / i7-1255U)

Extends zero-cpu/zero-power notes (`% of Maximum Frequency` + `Win32_Processor Current/MaxClockSpeed` + `powercfg` + plug state). Verdict per signal: collector or UNAVAILABLE with reason, cost, confound, inference.

| Signal | Verdict + collector | Cost | Confound | Inference |
|---|---|---|---|---|
| `MSAcpi_ThermalZoneTemperature` (root\wmi, deci-K) | EFFECTIVELY UNAVAILABLE: `Get-CimInstance -Namespace root/wmi MSAcpi_ThermalZoneTemperature` → Access Denied without admin on Win10/11. Try once, catch, log `thermal.zone=denied`. | ~400ms once | Even elevated: skin/chassis sensor, not die; often 1 stale zone on HP | `denied` is expected — fall back to freq proxy, never score as cool |
| `Win32_TemperatureProbe` | UNAVAILABLE (null-populated): class exists but `CurrentReading` NULL/`Unknown` on ACPI laptops. Query once to confirm, drop. | cheap once | Some desktops populate it; laptop NULL is normal | NULL ≠ cool; never score |
| LHM/OHM die temp | UNAVAILABLE: CPU DTS (`IA32_THERM_STATUS`) needs WinRing0 driver = admin install + HVCI/signing friction. Optional BYO: user-run LHM-as-admin JSON ingested out-of-band only. | n/a | TCC offset; P/E-die delta | No in-app temp; manual step only |
| Intel DTT visibility | UNAVAILABLE as API: DTT sets PL1/PL2/skin policy via EC, no public user-mode temp query; `Intel-DTT` ETW needs admin.
